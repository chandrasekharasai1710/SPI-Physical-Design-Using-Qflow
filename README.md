# Physical Design Implementation of SPI Using Qflow

- Implemented the physical design flow of a Serial Peripheral Interface (SPI) using Qflow.
- Used Verilog HDL for digital design representation.
- Configured the Qflow environment and technology files.
- Performed RTL synthesis using Yosys.
- Generated the gate-level netlist for physical implementation.
- Executed standard-cell placement using Graywolf.
- Analyzed circuit timing using Static Timing Analysis (STA).
- Performed routing to establish physical interconnections.
- Conducted post-routing timing analysis.
- Performed Design Rule Check (DRC) using Magic.
- Verified layout-to-netlist connectivity using Layout Versus Schematic (LVS).
- Used Netgen for LVS verification.
- Generated the physical layout in GDSII format.
- Followed the RTL-to-GDSII physical design workflow.
- Gained practical experience with open-source VLSI physical design tools.

**Tools & Technologies:** Verilog HDL, Qflow, Yosys, Graywolf, OpenSTA, Magic, Netgen.
